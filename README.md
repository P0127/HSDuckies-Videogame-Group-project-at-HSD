# HSDuckies

### Academic Project Overview
This repository contains a public copy of the collaborative videogame project HSDuckies, developed as part of the Media Informatics curriculum at Hochschule Düsseldorf (HSD). 

---

### How to Get the Game Started

#### Prerequisites
Before running the game, ensure you have the Godot Engine installed on your system. This project was developed using Godot version 4.x (Standard Support).

#### Steps to Run the Project
1. Clone or download this repository to your local machine.
2. Launch the Godot Engine Project Manager.
3. Click the **Import** button on the right-hand panel.
4. Navigate to the downloaded project folder, select the `project.godot` file, and click **Open**.
5. Once the project loads into the Godot Editor lick the Play icon in the top-right corner to launch and play the game.
